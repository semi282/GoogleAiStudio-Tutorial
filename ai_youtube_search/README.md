# 🎬 자막뽑기 AI (Zapok AI) - AI 유튜브 검색 & 자막 추출기

유튜브 영상 링크를 입력하면 **화자 분리(Diarization)** 및 **정밀 타임스탬프(`[MM:SS]`)**가 포함된 자막을 추출하고,
**자막의 타임스탬프를 클릭하면 해당 시간대의 영상으로 즉시 이동하여 자동 재생**할 수 있는 웹 서비스입니다.

동일한 유튜브 영상은 **`transcripts.csv` 파일에 영구 저장 및 캐싱**되어 매번 API를 다시 호출하지 않고 즉시 불러오므로 **0초 대기 & 0원 요금**으로 이용 가능합니다.

---

## 🌟 주요 핵심 기능

1. **원클릭 다이렉트 검색 & 자동 자막 추출**:
   - 상단 검색창에 유튜브 URL을 붙여넣고 엔터 또는 검색 버튼을 누르면 즉시 고속 오디오 추출 및 AI 전사가 시작됩니다.
2. **타임스탬프 클릭 시 영상 자동 이동 (Interactive Seek)**:
   - 각 대사 앞의 `[00:15]`, `[01:23]` 버튼을 클릭하면 유튜브 플레이어가 해당 시간대로 정확하게 점프하여 영상을 재생합니다.
3. **CSV 데이터베이스 기반 스마트 캐싱 (`transcripts.csv`)**:
   - 추출된 자막, 요약, 메타데이터가 `transcripts.csv`에 자동으로 기록됩니다.
   - 이미 분석했던 영상 링크를 다시 입력하면 **Gemini API 호출 없이 즉시 캐시에서 로드**됩니다.
4. **Google AI Studio 요금 실시간 표시**:
   - 오디오 초당 단가 및 토큰량을 계산하여 **USD($)와 KRW(₩, 환율 1,400원 기준)**를 동시에 안내하며, 무료 티어(일 1,500회) 혜택을 명시합니다.
5. **AI Q&A 어시스턴트 & 3줄 핵심 요약**:
   - **`Gemini 3.8 Flash (v1.0)`** 기반으로 영상 전체 대본에 대해 자유롭게 질문하고 답변을 받을 수 있습니다.
6. **접이식 패널 레이아웃 (Collapsible Drawers)**:
   - **왼쪽 서랍**: CSV에 저장된 이전 분석 히스토리 목록을 원클릭으로 열람.
   - **오른쪽 서랍**: 스크립트 뷰어(복사/TXT 다운로드), AI 질문하기, 3줄 요약.

## 📁 프로젝트 파일 구조

```text
ai_youtube_search/
├── index.html        # 자막뽑기 AI 프론트엔드 (타임스탬프 클릭 점프 & 접이식 패널)
├── server.py         # FastAPI 백엔드 웹 서버 (포트 8000)
├── db.py             # CSV 데이터베이스 관리 및 캐싱 모듈 (transcripts.csv)
├── transcripts.csv   # 추출된 유튜브 링크 & 자막 데이터베이스 저장소
├── transcriber.py    # 화자 분리 및 [MM:SS] 정밀 타임스탬프 STT & Q&A 엔진
├── cost_calc.py      # Google AI Studio 공식 요금 계산기 (USD / KRW)
├── downloader.py     # 초고속 영상 정보 조회 및 고음질 오디오 다운로더
├── requirements.txt  # 의존 패키지 목록
└── README.md         # 서비스 매뉴얼 및 버전 변경 이력
```
